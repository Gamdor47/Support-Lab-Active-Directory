# Architecture du projet

## Infrastructure

* 2 domaines Active Directory
* 3 contrôleurs de domaine Windows Server
* 1 poste client Windows

## Domaines

* super.local
* meilleur.local

## Services configurés

* Active Directory Domain Services
* DNS
* LDAP
* Kerberos
* Global Catalog

## Fonctionnalités mises en œuvre

* Création et gestion d'utilisateurs
* Gestion des groupes de sécurité
* Création d'OU
* Déploiement de GPO
* Administration locale déléguée
* Déploiement logiciel via GPO
* Gestion des rôles FSMO
* Jonction de postes au domaine

## Outils utilisés

* Windows Server 2025
* Windows 11
* PowerShell
* GPMC
* DNS Manager
