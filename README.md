# Support-Lab-Active-Directory

## Présentation

Ce projet a pour objectif de reproduire un environnement informatique d'entreprise afin de développer des compétences en administration système et support utilisateurs.

## Environnement technique

* Windows Server 2022
* Active Directory
* DNS
* DHCP
* GLPI
* Windows 10
* Windows 11

## Compétences développées

* Création et gestion des utilisateurs Active Directory
* Administration des groupes et droits d'accès
* Configuration DNS et DHCP
* Déploiement et configuration de postes clients
* Gestion des incidents via GLPI
* Support utilisateurs N1/N2
* Rédaction de documentation technique

## Objectifs du projet

* Simuler une infrastructure informatique professionnelle
* Développer des compétences d'administration Windows
* Mettre en pratique les bonnes pratiques du support informatique
* Préparer une insertion professionnelle en alternance
