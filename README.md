# Support-Lab-Active-Directory

## Présentation

Projet réalisé dans le cadre de ma formation BTS SIO SISR.

Ce laboratoire reproduit une infrastructure Active Directory d'entreprise avec plusieurs contrôleurs de domaine, DNS, GPO et déploiement logiciel.

## Technologies utilisées

* Windows Server 2025
* Active Directory
* DNS
* GPO
* Windows 11

## Compétences développées

* Administration Active Directory
* Gestion des utilisateurs et groupes
* Configuration DNS
* Gestion des GPO
* Déploiement logiciel
* Support utilisateurs
